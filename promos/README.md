# Plugin Store promo images

Marketing images for the Sevvies listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-sevvies](https://justinholt.com/plugins/craft-sevvies).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `sevvies-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

Chrome is occasionally OOM-killed partway through a full run. Rebuild the missing slides
individually — `./build.sh "5"` — rather than assuming the deck is finished because the command
exited.

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, app icon, price | — |
| 2 | One checkout, four different documents | the whole pitch: four VAT rules from one cart |
| 3 | Why is this one zero-rated? | the recorded reason, on the invoice |
| 4 | It will not file the wrong number | reconciliation catching a net/gross mismatch |
| 5 | A rate the rule cannot carry | the refusal, with the reason |
| 6 | One order. One document. Ever. | the unique index refusing retries |
| 7 | Dry run the whole thing | console preview output |

Every slide is pure CSS and type — there are no control-panel screenshots. When the CP settles,
screenshot slides can be added alongside these without redoing anything.

## Palette

Sevvies is coloured after **sevDesk**, the way Shipper is coloured after ShipStation: indigo chrome
(`#212144`, `#141430`) with sevDesk's coral accent (`#F85B45`) and a violet secondary (`#534ACC`).
Jersey 20 for display, Inter for body — the family's fonts.

## Assets

- `icon.svg` — a straight copy of `../src/icon.svg`, used for the cover mark and the footer lockup.
  Re-copy it whenever the icon changes.
- `watermark.svg` — **the tick alone.** Two things were stripped and should stay stripped: the
  document frame, whose bars at watermark scale read as a hard-edged box across the slide, and the
  ruled lines, which read as grey UI pills sitting behind the copy.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
